Z System Spaces

An easy deployment system for getting your next data science program up and running on Z System.

What are spaces

Spaces are isolated environments that run on nodes in the Z System cluster. Each space is a container that has a specific runner installed. You can start and stop spaces as needed.

Z Architecture

Z System is designed to be efficient and powerful. Spaces has 4 runner classes

OMEGA

Maximum power, maximum performance.

APEX

High performance, lower footprint.

MICRO ARM

Low power, ARM CPUs.

NANO

AMD GX-217GA SOC, Ultra low power, minimal footprint.
